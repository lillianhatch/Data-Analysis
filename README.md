# Statistical Data Analysis

A collection of statistical modeling and exploratory data analysis (EDA) case studies using Python, R, and JMP.

### Included Case Studies
* **Survival Analysis (`Hatch_effectsCarcinogen.pdf`):** Kaplan-Meier survival curves and Cox Proportional Hazards modeling.
* **Morphometrics (`Hatch_flowerPCA.pdf`):** PCA dimensionality reduction and K-means clustering.
* **Multivariate Regression (`Hatch_JMPCaseAnalysis.pdf`):** Modeling relationships between mammalian sleep, gestation, and predation.
* **NHANES EDA (`LillianHatch_Report.pdf`):** Exploratory data analysis investigating mental health, sleep, and physical activity.
* **Bacterial Growth (`Hatch_bacterialGrowth.pdf`):** Statistical analysis of bacterial growth patterns.
