# Statistical Data Analysis

A collection of statistical modeling and exploratory data analysis (EDA) case studies using Python, R, and JMP.

### Included Case Studies
* **Carcinogen Effects in Rats (`Hatch_effectsCarcinogen.pdf`):** Analysis of treatment group survival times using Kaplan-Meier curves, life-distribution analysis, and Cox Proportional Hazards modeling.
* **Flower Morphometrics (`Hatch_flowerPCA.pdf`):** Applied Principal Component Analysis (PCA) to petal and sepal dimensions to evaluate variance and identify species clusters.
* **Mammalian Sleep & Gestation (`Hatch_JMPCaseAnalysis.pdf`):** Investigated the relationship between gestation length and sleep stages (TST, NREM, REM) across 79 species using linear regression and K-means clustering in JMP.
* **NHANES Mental Health EDA (`LillianHatch_Report.pdf`):** Used exploratory data analysis and linear regression on NHANES data to evaluate the impact of sleep duration and physical activity frequency on mental health.
* **Bacterial Growth Optimization (`Hatch_bacterialGrowth.pdf`):** Conducted experimental design analysis in JMP to evaluate how interactions between temperature, pH, glucose, shaking, and incubation time impact bacterial yield.
